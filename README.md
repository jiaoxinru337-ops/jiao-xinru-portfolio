# 焦欣茹｜策划研究作品集

15页中文个人作品集，采用原生HTML、CSS与JavaScript，无需构建。

本地打开 `index.html` 即可浏览。支持目录导航、方向键翻页、图片放大、减少动态效果和浏览器打印。

## GitHub Pages

将本目录全部内容推送到GitHub仓库，保留 `assets/` 的目录结构与 `.nojekyll` 文件。

在仓库的 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/ (root)**，保存。

网站地址以GitHub Pages设置页面返回的地址为准。访客无需登录GitHub。

项目内容与图像来自作者提供的资料；仓库公开不代表授予素材再利用许可。
